# 📊 Análise de Dados de Oficina Automotiva

## 📌 Sobre o projeto
Este projeto foi desenvolvido com o objetivo de aplicar conhecimentos de Banco de Dados e SQL em um cenário de uma oficina automotiva.

O banco de dados permite armazenar e analisar informações relacionadas a clientes, veículos, serviços e ordens de serviço.

## 🎯 Objetivos
- Criar e organizar um banco de dados
- Praticar consultas SQL
- Analisar informações de serviços realizados
- Calcular faturamento
- Identificar os serviços mais realizados
- Desenvolver conhecimentos voltados à área de Dados

## 🛠️ Tecnologias
- SQL
- Banco de Dados
- Git
- GitHub

## 📊 Análises
O projeto permitirá realizar consultas como:
- Faturamento total da oficina
- Faturamento por período
- Serviços mais realizados
- Valor médio das ordens de serviço
- Histórico de serviços por veículo

## 📈 Resultados da Análise

Após a criação do banco de dados e execução das consultas SQL, foram obtidos os seguintes resultados:

- 💰 Faturamento total: R$ 1.300,00
- 🎯 Ticket médio por ordem de serviço: R$ 325,00
- 🔧 Ordens de serviço analisadas: 4
- 🚗 Veículos cadastrados: 3
- 👥 Clientes cadastrados: 3

### 🔎 Análises realizadas

Foram utilizadas consultas SQL para:

- Relacionar clientes, veículos, serviços e ordens de serviço utilizando JOIN
- Calcular o faturamento total utilizando SUM
- Calcular o ticket médio utilizando AVG
- Identificar a quantidade de cada serviço utilizando COUNT e GROUP BY
- Organizar os resultados utilizando ORDER BY

### 💡 Conclusão

O projeto permitiu aplicar conceitos de modelagem de banco de dados e análise de dados em um cenário de oficina automotiva. Com as consultas SQL, foi possível transformar os dados cadastrados em informações úteis para acompanhamento dos serviços e do faturamento.
